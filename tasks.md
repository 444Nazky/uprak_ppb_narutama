# Checklist Tugas Aplikasi Data Siswa

## 1. Pembuatan Aplikasi Android (Wajib CRUD)
Gunakan Android Studio, Flutter, atau framework yang ditentukan guru untuk membuat aplikasi **"Aplikasi Data Siswa"** dengan ketentuan:

- [ ] **Halaman Login**
  - Form input `username` dan `password`.
  - Validasi input (tidak boleh kosong / harus sesuai).
  - Tombol **Login** untuk masuk ke Dashboard.

- [ ] **Halaman Dashboard**
  - Menampilkan nama aplikasi.
  - Menu navigasi ke fitur-fitur utama.
  - Menampilkan total jumlah data siswa secara *real-time*.
  - Tampilan menarik dan responsif.

- [ ] **Halaman Data Siswa**
  - Menampilkan daftar seluruh siswa (Nama, NIS, Kelas, Alamat).
  - Fitur pencarian (Search) data siswa.

- [ ] **Halaman Tambah Data Siswa**
  - Form input: **NIS**, **Nama Siswa**, **Kelas**, dan **Alamat**.
  - Tombol **Simpan**.

- [ ] **Fitur Edit & Hapus Data**
  - Bisa mengubah (update) data siswa yang sudah ada.
  - Bisa menghapus data siswa.
  - Wajib muncul pop-up/dialog konfirmasi sebelum data dihapus.

- [ ] **Penyimpanan Data (Database)**
  - Simpan data menggunakan SQLite, Firebase, atau penyimpanan lokal.
  - Data tidak boleh hilang saat aplikasi ditutup dan dibuka kembali.

- [ ] **Halaman Profil**
  - Menampilkan informasi pengguna yang login.
  - Tombol **Logout** untuk keluar kembali ke halaman Login.
